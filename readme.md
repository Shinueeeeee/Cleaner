TEMİZLEYİCİ — x64 Release Kurulumu
by Shinueeeeee

Kurulum:
1. Cleaner_1.0.0.0_x64_Test klasörünü aç.
2. Install.ps1 dosyasına sağ tıklayıp PowerShell ile çalıştır.
3. Windows'un gösterdiği yerel yayıncı sertifikası onayını kabul et.
4. Kurulum tamamlanınca Başlat menüsünden “Cleaner by Shinueeeeee” uygulamasını aç.

Paket: Cleaner_1.0.0.0_x64_Test\Cleaner_1.0.0.0_x64.msix
Mimari: Windows x64
Release: 1.0.0.0

Bu paket, yayıncı kimliğiyle eşleşen yerel geliştirme sertifikasıyla imzalanmıştır.
Windows ilk kurulumda bu sertifikayı güvenilir olarak onaylamanı isteyebilir.
Sertifikanın açık anahtarı Shinue-Publisher.cer dosyasındadır. Özel anahtar paket klasörüne konmamıştır.

Bu yerel dağıtım paketi Microsoft Store veya herkese açık sertifika otoritesiyle imzalanmış değildir.
